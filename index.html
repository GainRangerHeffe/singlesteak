Common questions

More detail is in the user guide and the whitepaper.

What is Single Steak?

Single Steak is a staking platform on PulseChain. Any project can create a single-sided staking pool for its token, and holders stake that one token to earn rewards. No liquidity pair is needed, so there is no impermanent loss.

Is there a lock-up period?

No. You can unstake your tokens at any time.

Are rewards compounded automatically?

No. You claim rewards yourself, and you can stake them again if you want to.

What happens if a pool runs out of rewards?

Staking continues, but no new rewards are earned until the pool owner adds more reward tokens.

Which tokens can have a pool?

Any PulseChain-compatible ERC20 token.

What does it cost?

Creating a pool has a one-time fee paid in PLS, shown in the form before you confirm. Pools created by projects have no platform fee for staking or unstaking. The official STEAK pool has a 1% deposit tax and a 1% withdrawal tax.

Can a pool owner change the reward rate?

Yes, but every change waits out a 24-hour timelock before it takes effect, so stakers can see it coming.

Which wallets and network does it support?

MetaMask, OKX Wallet, Rabby and Internet Money, on PulseChain only (chain ID 369).
